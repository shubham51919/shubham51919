## About Me

Full-stack developer with 3+ years shipping production software — e-commerce platforms, operational dashboards, enterprise applications, and mobile apps — across both startup and enterprise teams.

I work end-to-end in TypeScript: React, React Native and Next.js on the front end, Node.js and Express on the back end. I care a lot about clean architecture, performance, and real-time systems (Socket.IO), and I'm currently going deeper into PostgreSQL, database design, and system design.

These days I'm building and open-sourcing developer tooling around the React and real-time ecosystems.
